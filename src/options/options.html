Canvas Homework Compiler — Settings

Everything below is stored only in this browser (chrome.storage.local) and is sent only to the exact Canvas domain and LLM endpoint you configure here. Nothing is sent anywhere else.

Canvas

Generate one under Canvas → Account → Settings → "New Access Token". If your school blocks tokens, leave this blank — the extension will fall back to using your normal logged-in session.

LLM Provider

Any OpenAI-compatible chat-completions endpoint (base URL should NOT include /chat/completions).

Some providers (IFM included) reject requests made directly from a browser/extension origin. If Test LLM fails with something like model_origin_not_allowed but works fine from curl, that's why — see proxy/README.md in this project for a small server-side forwarder that fixes it. If you use it, set Base URL to your deployed proxy URL and API Key to the proxy's shared secret (not your real provider key).

Gradescope (for Calendar Sync)

Gradescope has no personal access token option, so this uses your normal logged-in browser session (same approach as the Canvas fallback) — just make sure you're logged into Gradescope in this browser.

Google Calendar (for Calendar Sync)

Due dates are synced into a dedicated "Homework Compiler" calendar in your Google account — it won't touch your existing calendars. Requires a one-time Google sign-in prompt the first time you sync.
